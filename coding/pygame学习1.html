通过示例程序学习pygame

以下示例程序基于pygame官网实例修改，通过实现一个简单的游戏窗口，展示如何使用pygame进行基本的初始化、事件处理、图形渲染和游戏循环。

import pygame

def game_setup():
    pygame.init()
    screen = pygame.display.set_mode((1280, 720))
    clock = pygame.time.Clock()
    running = True
    dt = 0
    player_pos = pygame.Vector2(screen.get_width() / 2, screen.get_height() / 2)

    while running:
        for event in pygame.event.get():
            if event.type == pygame.QUIT:
                running = False

        pygame.draw.circle(screen, '#666666', player_pos, 40)

        keys = pygame.key.get_pressed()
        if keys[pygame.K_w]:
            player_pos.y -= 300 * dt
        if keys[pygame.K_s]:
            player_pos.y += 300 * dt
        if keys[pygame.K_a]:
            player_pos.x -= 300 * dt
        if keys[pygame.K_d]:
            player_pos.x += 300 * dt

        pygame.display.flip()
        clock.tick(60)
        dt = clock.tick(60) / 1000

    pygame.quit()

if __name__ == '__main__':
    game_setup()

功能分析

1. 初始化

pygame通过pygame.init()进行初始化，这一步是必须的，它负责加载pygame的所有模块，为后续操作做好准备。

pygame.init()

pygame 初始化后，会加载以下模块：

  • pygame.display：用于控制显示窗口或屏幕
  • pygame.event：用于处理事件
  • pygame.image：用于加载和操作图像
  • pygame.mixer：用于处理声音
  • pygame.font：用于处理字体
  • pygame.time：用于控制时间和帧率

2. 显示窗口

使用pygame.display.set_mode()创建游戏窗口，参数是窗口的尺寸（宽×高）。这展示了pygame的窗口管理功能。

screen = pygame.display.set_mode((1280, 720))

可以通过display进行以下设置：

  • 设置窗口标题：pygame.display.set_caption("Your Game Title")
  • 设置窗口图标：pygame.display.set_icon(pygame.image.load("icon.png"))
  • 创建全屏窗口：screen = pygame.display.set_mode((1280, 720), pygame.FULLSCREEN)

3. 事件处理

pygame通过事件队列处理用户输入和系统事件。pygame.event.get()用于获取事件队列中的事件，支持键盘、鼠标等多种输入。

for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False

一些常见的事件类型包括：

  • pygame.QUIT：点击关闭按钮
  • pygame.KEYDOWN：按键按下
  • pygame.KEYUP：按键松开
  • pygame.MOUSEBUTTONDOWN：鼠标按钮按下
  • pygame.MOUSEBUTTONUP：鼠标按钮松开
  • pygame.MOUSEMOTION：鼠标移动

4. 图形绘制

pygame提供了多种图形绘制函数，如pygame.draw.circle()用于绘制圆。通过指定屏幕对象、颜色、位置和半径，可以在窗口上绘制图形。

pygame.draw.circle(screen, '#666666', player_pos, 40)

可以通过draw绘制其他图形：

  • pygame.draw.rect(screen, color, (x, y, width, height))：绘制矩形
  • pygame.draw.line(screen, color, start_pos, end_pos, width)：绘制线
  • pygame.draw.polygon(screen, color, points)：绘制多边形

pygame也提供了加载和显示图像的功能：

  • player_image = pygame.image.load('player.png')
  • screen.blit(player_image, (x, y))

5. 帧率控制

pygame.time.Clock用于控制游戏的帧率。clock.tick(60)确保游戏以60帧每秒的速度运行，保持游戏的流畅性。

clock = pygame.time.Clock()
clock.tick(60)

6. 键盘输入检测

通过pygame.key.get_pressed()获取当前键盘按键状态，实现对WASD键的检测，用于控制游戏对象的移动。

keys = pygame.key.get_pressed()
if keys[pygame.K_w]:
    player_pos.y -= 300 * dt

7. 显示更新

使用pygame.display.flip()更新整个屏幕的显示，确保所有绘制操作都呈现给用户。

pygame.display.flip()

如果只需要更新屏幕的一部分，也可以使用：

pygame.display.update(pygame.Rect(x, y, width, height))

8. 游戏主循环

pygame游戏通常基于主循环结构，包含事件处理、更新游戏状态、渲染图形等步骤。

while running:
    # 事件处理
    # 更新游戏状态
    # 渲染图形

9. 程序出口

游戏结束时，使用pygame.quit()退出pygame，释放资源。

pygame.quit()

总结

通过以上示例程序，我们学习了pygame的以下功能：

  • 初始化与资源管理：通过pygame.init()和pygame.quit()管理资源
  • 窗口管理：使用pygame.display.set_mode()创建和控制窗口
  • 事件处理：通过事件队列处理用户输入和系统事件
  • 图形绘制：提供丰富的图形绘制功能，如绘制圆、矩形等
  • 帧率控制：通过pygame.time.Clock控制游戏帧率
  • 输入检测：支持键盘输入检测，用于游戏控制
  • 显示更新：通过pygame.display.flip()更新屏幕显示

pygame的强大之处在于它提供了构建2D游戏所需的基本功能，从窗口管理到图形绘制，从事件处理到声音控制，为游戏开发者提供了一个全面的工具集。无论是简单的原型设计还是完整的游戏开发，pygame都能满足需求。
